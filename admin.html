🎂 Birthday Link Generator

📋 Hướng Dẫn Sử Dụng:

  • Preview: Xem trước trang sinh nhật
  • Copy Link: Sao chép link để chia sẻ
  • Mỗi người sẽ có tên, ảnh và màu theme riêng
  • Để thêm người mới, chỉnh sửa file config.js

🔧 Cách Thêm Người Mới (Format Mới - Tối Ưu):

  1. Bước 1: Tạo folder trong res/img/ (ví dụ: nguyen-van-a)
  2. Bước 2: Thêm ảnh với tên: 1.jpg, 2.jpg, 3.jpg, ...
    ⚠️ Ảnh phải đánh số liên tục từ 1, không được bỏ số
  3. Bước 3: Mở file config.js và thêm vào PERSON_CONFIGS: 
    nguyenvana: {
    name: 'Nguyễn Văn A',
    folder: 'nguyen-van-a',        // tên folder
    extension: 'jpg',              // đuôi file ảnh
    photoCount: 5,                 // số lượng ảnh
    customMessage: 'Chúc {name} sinh nhật vui vẻ!',
    themeColor: '#ffd700'
}
  4. Reload trang này để thấy người mới
  5. 📖 Xem hướng dẫn chi tiết
